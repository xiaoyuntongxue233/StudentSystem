# 小型学生管理系统

一个用 Java Swing 编写的小型学生管理系统，支持 **管理员 / 成员 / 访客** 三种角色，
包含成员管理、活动管理与报名（正式名单 + 候补名单）、数据导入导出等功能。

## 运行环境

- JDK 11 及以上（开发时使用 JDK 25 验证通过）
- 不需要任何第三方依赖

## 运行方式

在项目根目录执行：

```bash
# 编译（Windows PowerShell）
javac -encoding UTF-8 -d bin (Get-ChildItem -Recurse -Filter *.java src).FullName

# 运行
java -cp bin main.Start
```

也可以直接用 Eclipse / VS Code 打开（项目已带 `.classpath` 和 `.vscode` 配置），
入口类是 `src/main/Start.java`。

## 默认账号

首次运行时程序会在 `data/` 下自动生成数据文件，并写入三个默认账号：

| 角色 | ID | 一级密码 | 二级密码 |
| --- | --- | --- | --- |
| 管理员 | `admin` | `123456` | `123456` |
| 成员 | `member` | `123456` | 无 |
| 访客 | `guest` | `123456` | 无 |

## 功能简介

### 管理员

- **成员管理**：添加、修改、删除成员，按 ID / 姓名搜索，按年龄 / 班级 / ID 排序。
  角色升降级、删除自己等敏感操作需要二级密码确认。
- **活动管理**：创建、修改、删除活动，设置开始/结束时间、人数上限和候补人数，
  查看每个活动的报名名单（区分正式名单与候补名单）。
- **管理员口令管理**（V0.2 新增，菜单：`口令 → 管理员口令管理`）：
  添加、删除、查询用于注册新管理员的口令。
- **导入导出**：把成员数据导出为文本文件，或从文本文件导入（支持追加 / 替换）。

### 成员

- 查看队员信息（手机号自动脱敏）。
- 报名 / 取消报名活动，正式名单满员时可加入候补名单。

### 访客

- 只读查看队员信息和活动信息（手机号自动脱敏）。

## 目录结构

```
src/
├── main/          程序入口
├── job/           实体类（User / Person / Student）
├── chain/         手写单向链表（用户表、学生表）
├── storage/       数据持久化（对象序列化）
├── thingstodo/    业务逻辑（活动、报名名单、管理员口令、验证码、时间）
└── ui/            界面
    ├── login/         登录
    ├── register/      注册
    ├── adminpage/     管理员
    ├── memberpage/    成员
    └── guestpage/     访客
data/              运行时数据文件（*.dat，不纳入版本管理）
```

## 注册管理员说明

注册管理员时需要填写「管理员口令」。口令来源有两种：

1. 由已有管理员登录后在 `口令 → 管理员口令管理` 中添加（保存在 `data/adminTokens.dat`）；
2. 通过环境变量 `STUDENT_SYSTEM_ADMIN_TOKEN` 或启动参数 `-Dstudent.system.admin.token=xxx` 配置。

第一次使用时，可以先用默认管理员账号 `admin` 登录，到口令管理界面添加一条口令，
之后再注册新的管理员账号。
